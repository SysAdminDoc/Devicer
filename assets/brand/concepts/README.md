# Devicer artwork archive

Four original logo studies are preserved here without alteration. The selected device-and-shield direction remains the product identity; this archive does not replace it with an alternate.

| Study | Status |
|---|---|
| [Device bridge](direction-01-device-bridge.png) | Early phone-to-desktop concept. Not selected. |
| [Selected device shield](direction-02-selected-device-shield.png) | Current identity. The [selected master](../devicer-selected-master.png) is an identical original copy. |
| [Light device shield](direction-03-device-shield-light.png) | Alternate with a baked-in checkerboard. This is an opaque image, not a transparent production logo. |
| [Minimal device shield](direction-04-device-shield-minimal.png) | Alternate with a baked-in checkerboard. Preserved for reference only. |

The [selection record](selection.json) identifies the approved direction. The [production mark](../devicer-mark-master.png) and [small-size master](../devicer-mark-small-master.png) remain separate from these original studies. Keep the originals when exporting new delivery sizes.
